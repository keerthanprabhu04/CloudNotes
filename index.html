Serverless Academic Workspace

Organize, store, and access your academic documents from anywhere.

CloudNotes pairs Amazon Cognito authentication, private encrypted Amazon S3 storage, DynamoDB metadata indexing, and Python 3.12 AWS Lambda APIs in a clean student workspace.

Create Student Account Sign In to Workspace

Cognito JWT Security

Every student signs in with Amazon Cognito. API Gateway validates JWT claims before Lambda derives ownership strictly from your Cognito user ID.

Direct S3 Presigned Transfers

Documents upload directly to a private, AES-256 encrypted Amazon S3 bucket using short-lived presigned POST policies capped at 10 MB.

Instant DynamoDB Search

Metadata is partitioned by user_id in CloudNotesDocuments so listing, filtering by file type, and storage metrics load in milliseconds.

Serverless Request Lifecycle

01. Authenticate

Amazon Cognito verifies student credentials and issues short-lived ID and Access JWT tokens.

02. Authorize

API Gateway HTTP API validates the Bearer JWT and passes claims to Python 3.12 Lambda.

03. Store Privately

Files upload straight to private S3 via presigned POST while DynamoDB tracks metadata.

04. Monitor

All Lambda executions and authorization errors stream automatically to Amazon CloudWatch.
